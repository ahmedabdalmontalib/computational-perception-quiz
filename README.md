# Computational Perception · Quiz: Labs 1 to 3

An 82-question practice quiz on Labs 1–3 (Images, Pixels and Cameras · Colour and Shapes · Learning from Examples).
Students sign in with their full name (الاسم ثلاثي) and group number, then answer by clicking only.
Each explanation names the part of the lab sheet to read again. After **Finish**, **Redo my mistakes**
starts a round with only the wrong questions, in a new order, until every question has been answered right.

Prepared by Ahmed M. AbdAl-Montalib.

## Open the quiz

Open the quiz page in a browser (Chrome, Edge, Firefox or Safari, on a computer or a phone).
The page is a single file, `index.html`, with nothing to install.

## Put it on GitHub Pages

1. Create a repository on GitHub and upload `index.html` and this `README.md` to its main branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*, choose the branch **main** and the folder **/ (root)**, and press **Save**.
4. After a minute or two, the page shows the address of the quiz, such as
   `https://<your-user-name>.github.io/<repository-name>/`. Give this address to the students.

A link to the file itself (`github.com/.../index.html`) shows its code, not the quiz: always give the students the `github.io` address.

## Good to know

- Each student's name and answers stay in their own browser. Nothing is sent anywhere, and the page does not collect scores.
- **Sign out for the next student** clears the name and answers, for shared computers.
- The quiz works offline too: students can save `index.html` and open it from their computer.
